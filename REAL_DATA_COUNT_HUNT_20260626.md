# Count real-data hunt, 2026-06-26

Goal: find one defensible count-response real-data example for the non-identical mixture GLM paper.

## Prepared candidates

New prepared datasets were generated by `experiments/real_data/prepare_count_datasets.py`.

- `anes_tvnews`: American National Election Survey 1996, response = number of TV-news viewing days per week. `n=944`, `p=20`, zero fraction `0.171`.
- `star98_above`: California school districts, response = number of students above the national median in math. `n=303`, `p=22`, zero fraction `0.000`.
- `star98_below`: California school districts, response = number of students below the national median in math. `n=303`, `p=22`, zero fraction `0.000`.
- `bike_hour`: UCI Bike Sharing hourly data, response = total hourly rentals. `n=17379`, `p=54`, zero fraction `0.000`.
- `online_news_shares`: UCI Online News Popularity, response = number of shares. `n=39644`, `p=59`, zero fraction `0.000`.

Fair affairs was inspected but not used as a count example because the response is not integer-valued. Committee, capital-punishment, and strike-duration datasets were inspected but are too small for a serious primary real-data example.

## Cheap local screens

All screens used count families `{poisson, nb2, zip, zinb}` and GLM-informed K-means initialization.

### Built-in datasets

Output directory: `experiments/real_data/count_hunt/local_builtin_k12`.

- `anes_tvnews`: BIC selected an identical `poisson+poisson` model. Best non-identical model was `poisson+zip`, but it lost to the identical mixture by about 5.34 BIC units.
- `star98_above`: BIC selected identical `zinb+zinb`; the best non-identical model did not beat either the identical mixture or the best K=1 model.
- `star98_below`: BIC selected identical `nb2+nb2`; the best non-identical model did not beat either the identical mixture or the best K=1 model.

Conclusion: these are useful comparators only. They are not primary count examples.

### Larger UCI datasets

Output directory: `experiments/real_data/count_hunt/local_uci_k12`.

- `online_news_shares`: BIC selected identical `nb2+nb2`; best non-identical `nb2+zinb` was close but did not win BIC.
- `bike_hour`: BIC selected non-identical `nb2+zinb` with `lambda=10`. This beat the best K=1 model by about 100 BIC units, but only beat the best identical mixture by about 0.11 BIC units in the cheap screen.

Additional bike-focused screen:

- Output directory: `experiments/real_data/count_hunt/local_bike_penalty_k2`.
- With `p_screen=35` and penalties up to 500, BIC again selected non-identical `nb2+zinb` with `lambda=20`.
- This beat identical `zinb+zinb` by about 1.03 BIC units and identical `nb2+nb2` by about 2.65 BIC units.
- Active counts remained dense (`[31, 31]`), with four features differing across components.

Interpretation: `bike_hour` is the only count dataset so far with a reproducible non-identical BIC winner. The cheap local evidence is promising but not yet publishable because the BIC margin over the best identical mixture is small and the selected models remain dense.

## Full cluster-screen result

The cluster run completed successfully with exit code 0.  The results are in
`experiments/real_data/targeted_outputs/count_hunt_v1`.

### Bike sharing hourly counts

The promising local signal did not hold up under the fuller search.

- BIC winner: identical `nb2+nb2`, K=2, `lambda=10`, quantile-GLM initialization.
- BIC: `32906.294`; held-out log likelihood: `-8069.674`; RMSE: `101.105`; MAE: `71.444`.
- Mixing weights: `[0.473, 0.527]`.
- Active counts: `[34, 34]`.
- Best K=1 BIC: `nb2`, `lambda=20`, BIC `33683.055`.
- Best non-identical BIC: `nb2+zinb`, K=2, `lambda=0`, BIC `32920.605`.
- The best non-identical model improves substantially over the best K=1 model but loses to the best identical mixture by `14.311` BIC units.
- The held-out log-likelihood winner is also identical: `zinb+zinb+zinb`, K=3, `lambda=2`.

Conclusion: `bike_hour` supports mixture modeling and overdispersed count components, but not the non-identical-family claim.  It should not be used as the main count example.

### Online news shares

The online-news data also do not provide the desired count example.

- BIC winner: identical `nb2+nb2+nb2`, K=3, `lambda=100`, K-means-GLM initialization.
- BIC: `52186.000`; held-out log likelihood: `-12981.300`; RMSE: `9481.135`; MAE: `3164.065`.
- Mixing weights: `[0.340, 0.151, 0.510]`.
- Active counts: `[9, 1, 19]`.
- Best K=1 BIC: `nb2`, `lambda=50`, BIC `54189.994`.
- Best non-identical BIC: `nb2+nb2+zinb`, K=3, `lambda=100`, BIC `52193.382`.
- The best non-identical model improves strongly over the best K=1 model but loses to the best identical mixture by `7.382` BIC units.
- The held-out log-likelihood winner is non-identical, `nb2+nb2+zinb`, K=3, `lambda=50`, but the improvement over the best identical model is very small and the corresponding BIC is worse.

Conclusion: `online_news_shares` gives a useful robustness/comparator result, not a primary success case.

## Decision

The full count-screen results are not publishable as the paper's count-data example.  The honest interpretation is that both large count datasets support latent heterogeneity, but the selected heterogeneity is adequately captured by identical negative-binomial or zero-inflated negative-binomial families.  We should not write either dataset as evidence for non-identical mixtures.

The continuous real-data example remains strong:

- `parkinsons_log`: BIC winner `student_t+skew_normal+skew_normal`, K=3, `lambda=20`, BIC `1452.180`.
- It beats the best K=1 model by about `416.380` BIC units and the best identical mixture by about `43.378` BIC units.
- Active counts are `[14, 12, 16]`, with meaningful component-specific voice-measure patterns.

Next count-data strategy: prioritize responses with genuine zero inflation or multiple count-generating mechanisms, not merely overdispersion.  Candidate classes include health-utilization with many non-users plus high utilizers, insurance claims with structural zeros, and ecological abundance/count data with detection or habitat components.  The current UCI bike and online-news examples are too well explained by identical negative-binomial mixtures.
