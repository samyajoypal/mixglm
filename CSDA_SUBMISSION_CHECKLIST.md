# CSDA Submission Checklist

## Files Prepared

- `csda_submission/main.tex`: standalone main article
- `csda_submission/supplementary.tex`: standalone supplementary material
- `csda_submission/references.bib`: shared bibliography database
- `csda_submission/fig1.pdf` through `fig5.pdf`: sequential article figures
- `csda_submission/main.pdf`: compiled article for author review
- `csda_submission/supplementary.pdf`: compiled supplement for author review
- `csda_editorial_manager_source.zip`: flat source archive for Editorial Manager

The source archive also contains the CAS single-column class, bibliography
style, common style, and six small interface-thumbnail assets needed for a
self-contained compile. It contains no auxiliary, log, checkpoint, or raw
experiment files.

## Editorial Manager Mapping

1. Upload `main.pdf` as the manuscript PDF if the system requests a rendered manuscript.
2. Upload `supplementary.pdf` as supplementary material for review.
3. Upload `csda_editorial_manager_source.zip` when source files are requested.
4. Keep `fig1.pdf` through `fig5.pdf` as separate figure files only if the system asks for individual figures in addition to the source archive.

The Elsevier CAS class places highlights on an unnumbered first page of the
compiled main PDF. The article itself begins on the following page.

## Author Confirmation Before Submission

- Confirm the corresponding-author email `palsamyajoy@gmail.com`.
- Confirm the author order and both affiliations.
- Confirm the declaration of no competing interests.
- Add any funding statement, acknowledgments, and CRediT author contributions agreed by all authors.
- Confirm that every coauthor approves the final title, claims, and public repository release.
- Create a tagged repository release and replace the moving repository URL with a DOI or archived release URL if one is available before submission.
